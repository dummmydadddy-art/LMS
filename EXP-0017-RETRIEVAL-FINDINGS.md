## 2. Vector Space Geometry & Dot-Product Forensics

### Static Code Audit: `backend/rag_service.php` L435-L442
```php
private function cosineSimilarity(array $vecA, array $vecB): float {
    $dot = 0.0;
    $normA = 0.0;
    $normB = 0.0;
    $len = count($vecA);
    for ($i = 0; $i < $len; $i++) {
        $dot += $vecA[$i] * $vecB[$i]; // <--- Missing bounds check on $vecB
        $normA += $vecA[$i] * $vecA[$i];
        $normB += $vecB[$i] * $vecB[$i];
    }
    return ($normA > 0 && $normB > 0) ? $dot / (sqrt($normA) * sqrt($normB)) : 0.0;
}
```

### Defect Analysis (W-21)
The loop indexes `$vecB[$i]` up to `count($vecA)`. If:
- `$vecA` is 1024-dimensional (e.g. generated by bge-large)
- `$vecB` is 768-dimensional (stored corpus generated by nomic-embed-text)
The PHP worker generates **256 `Undefined array key` notices per chunk comparison**. Over a corpus of 100 chunks, this emits 25,600 PHP notices in a single search, ballooning log files by megabytes, causing CPU throttling, and producing invalid cosine scores (`NaN` or corrupt floats).
